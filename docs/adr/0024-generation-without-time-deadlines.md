# 模型生成不限时，保留手动取消

2026-11-03，根据用户明确要求，取消模型调用的一小时限制，允许作者手动取消。

## 决定与取代范围

- 取代 ADR-0023 中保留活动时长上限的条款，以及冻结规划中生成根的 elapsed 时间拦截；其余请求次数、输出上限、记账、持久化及未知结果保护继续适用。
- 主进程不再设置根活动时长截止计时器，预留、发送和短细纲重试不再按累计活动时长拒绝。兼容生成执行器也取消会话截止检查与请求计时器。
- 新根 `maxActiveElapsedMs` 和生成回执 `deadlineAt` 使用 `0` 表示无限时；兼容参数 `deadlineMs` 接受非负整数但不再控制时长。字段保留以支持旧记录和归档，不使用 Infinity 或超长 setTimeout。
- 旧根的冻结预算与哈希保持原样，历史正数时限不再执行。活动时长仍记录。已写入的阻断码不自动清除，以免绕过请求次数或存储失败保护。
- 手动取消继续通过 AbortController 中止传输，并通过 Promise.race 结束等待，即使服务商未响应取消也可收尾。已经接收的可见文本继续落盘，迟到结果不能把已取消任务改为成功。
- 模型连接测试和工具执行自身的超时不属于本次生成限时变更；服务商和网络仍可能自行断开请求。

## 验证范围

虚拟时钟覆盖新旧时限配置等待超过两小时后仍未自动中止、手动取消与文本保留；恢复测试覆盖旧预算超过历史时限后继续发送、导入和定稿后处理继续执行。归档测试覆盖无限时预算的导出与恢复。测试不调用真实模型。
